IN PLAIN WORDS

A reaction is like a dance floor. The dancers (atoms, or groups of atoms) change partners.

There are five dances: pair up (formation), split up (decomposition), cut in (single replacement), and swap partners (double replacement). The fifth is combustion: burning a fuel in oxygen.

You can tell which dance it is just by looking at the equation. The equation always shows what is made.

CARBON MONOXIDE (CO)

CO is colourless, it has no smell, and it is poisonous. You can't see it or smell it, so homes have CO detectors near furnaces and fireplaces.

THE FIVE TYPES

Formation (or synthesis): A + B → AB. Two things join into one.

Decomposition: AB → A + B. One thing breaks apart.

Single replacement: A + BC → AC + B. A lone element takes another one's place.

Double replacement: AB + CD → AD + CB. Two compounds swap partners. An acid + a base (neutralization) is one of these.

Combustion: a hydrocarbon (made of only C and H) + O2 → CO2 + H2O.

THE FLOWCHART

Ask these in order. Stop at the first "yes".

  1. Hydrocarbon + O2 → CO2 + H2O? Combustion.
  2. Only one reactant? Decomposition.
  3. Only one product? Formation.
  4. A lone element on each side? Single replacement.
  5. Two compounds → two compounds? Double replacement.

WATCH OUT

Not everything that burns is combustion here. S8 + 8O2 → 8SO2 makes one product, so it is formation. Sulfur isn't a hydrocarbon.

HCl + KOH → KCl + H2O is double replacement. H and K swap partners. (It is also called neutralization.)
